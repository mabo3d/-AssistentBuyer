Cozmo Companion – GitHub Build

Diese Build-Version enthält keine Privaten-Stammdaten.

Enthalten:
- FastAPI-Backend
- User-Interface
- leere SQLite-Seed-Datenbank
- Cozmo-Connector
- Interne Dokumentation


Die Cozmo-Adresse wird erst lokal nach dem 1. App-Start konfiguriert.

## App bauen
GitHub und Copilot → `Build a App for Apple iPad/iPhone devices`.

Danach stehen alle nötigen Dateien zu Verfügung, die für die Erstellung
dieser App, für den App-Store
benötigt die die erstellung einer `Cozmo_Companion` App, ermöglichen
mit der erzeugten `Cozmo_Companion` App, bereit.
