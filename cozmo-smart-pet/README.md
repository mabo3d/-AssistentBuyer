# Cozmo – Smart-PET

Ein eigenständiger, deutschsprachiger Prototyp für Cozmo als autonomen Roboterbegleiter. Das Dashboard zeigt beispielhaft Persönlichkeit, Stimmung, Energie, erkannte Personen und erinnerte Orte. Aktionen wie Spielen, Erkunden und Laden aktualisieren eine lokale Simulation.

> **Wichtig:** Dies ist eine reine Browser-Demo. Sie verbindet sich nicht mit einem echten Cozmo und steuert weder Roboter noch Ladegerät. Dafür muss später eine passende Cozmo-SDK- und Hardware-Anbindung ergänzt werden.

## Starten

`index.html` in einem aktuellen Browser öffnen. Es werden keine Pakete oder externen Dienste benötigt.

## Projektstruktur

- `index.html` – Dashboard und Dialog
- `styles.css` – responsives Erscheinungsbild
- `app.js` – lokale Interaktionen und Simulationszustand
